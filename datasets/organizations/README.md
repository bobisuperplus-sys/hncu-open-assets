# 湖南城市学院 机构组织架构与人员资产库 (Organizations Dataset)

本目录为湖南城市学院（HNCU）官方组织架构、党政机关、教学二级学院及直属教辅机构的**第一手机构信息与人事职责资产库**。

---

## 🏛️ 核心设计哲学：防覆盖与版本历史溯源

学校的机构编制、处级/院级领导班子、各科室职能以及办公电话具有**强时效性**与**覆盖式变更**的特点（如换届轮岗、部门重组、职责调整）。
若仅保留最新页面，会导致历史时期的组织脉络与责任人信息彻底断裂，给往届毕业生文凭验真、历史办事流程溯源、校史考证带来不可逆的损失。

因此，本项目严格执行 **“当前生效视图（Active） + 历史快照版本库（History） + 变更履历（Changelog）”** 三层版本化归档规范：

## 📋 机构信息标准 Schema 规范

每一个机构目录下均规范维护两份核心资产：

### 1. `领导班子与人员分工.md`
必须包含：
- **基本信息**：更新日期、版本号、官方来源 URL、数据指纹（SHA-256）
- **现任领导名单**：姓名、职务/职称、分管领域、主持/负责工作
- **办公信息**：办公地点、办公座机、官方邮箱

### 2. `机构设置与科室职责.md`
必须包含：
- **部门/学院定位**：主要职能概括
- **内设科室/系室列表**：科室名称、负责人、科室具体业务职责
- **对外服务窗口**：面向师生/校友的办事服务电话、服务指南

### 3. `changelog.json`
记录格式规范：
```json
[
  {
    "version": "v1.0",
    "timestamp": "2026-09-12T16:00:00+08:00",
    "sha256": "abcdef...",
    "action": "initial_creation",
    "summary": "初始版本建立，采集教务处领导班子与科室职责"
  },
  {
    "version": "v1.1",
    "timestamp": "2026-10-15T09:30:00+08:00",
    "sha256": "123456...",
    "action": "personnel_change",
    "summary": "人事变动：副处长轮岗调整",
    "diff": {
      "target_file": "领导班子与人员分工.md",
      "changes": [
        {"field": "副处长", "old_value": "张三", "new_value": "李四"}
      ]
    }
  }
]
```

## 🔄 自动化版本流转机制

1. **指纹校验**：通过自动化巡检爬虫获取官方网页最新正文，计算内容 SHA-256 指纹；
2. **变动比对**：若与当前生效版本指纹一致，则仅更新检查时间戳，不做冗余写入；
3. **快照归档**：若指纹不一致，立即将当前生效文件复制并重命名归档至 `history/{YYYYMMDD}_{old_version}_{filename}.md`；
4. **覆盖生效**：将最新解析的 Markdown 文件写入当前生效文件，版本号递增；
5. **审计追溯**：在 `changelog.json` 中追加差异变动细节与事件说明。
