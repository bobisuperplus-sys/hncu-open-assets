# 湖南城市学院 机构组织架构与人员资产库 (Organizations Dataset)

本目录为湖南城市学院（HNCU）官方组织架构、党政管理机关、二级教学学院及直属教辅机构的**第一手机构信息与专任师资队伍资产库**。

---

## 🏛️ 核心设计哲学：防覆盖与版本历史溯源

学校的机构编制、处级/院级领导班子、各系室专任教师以及办公电话具有**强时效性**与**覆盖式变更**的特点（如换届轮岗、部门重组、职责调整、职称晋升）。
若仅保留最新页面，会导致历史时期的组织脉络与责任人信息彻底断裂，给往届毕业生文凭验真、历史办事流程溯源、校史考证带来不可逆的损失。

因此，本项目严格执行 **“当前生效视图（Active） + 历史快照版本库（History） + 变更履历（Changelog）”** 三层版本化归档规范：

## 📋 机构信息标准 Schema 规范

每一个机构目录下均规范维护核心资产文件：
1. **`领导班子与人员分工.md`**：官方来源 URL、生效版本、更新日期、职务、姓名、办公地点、座机电话、分管工作与联系系室；
2. **`机构设置与师资队伍.md`**（或 **`机构设置与科室职责.md`**）：内设管理科室、教学系部、教研室主任、专任教师名单（职称/学位）、科研平台与重点实验室；
3. **`changelog.json`**：严格记录每一次版本创建、人员变动、换届交接的历史日志与数据指纹。

## 🔄 自动化版本流转机制

1. **指纹校验**：通过自动化巡检爬虫获取官方网页最新正文，计算内容 SHA-256 指纹；
2. **变动比对**：若与当前生效版本指纹一致，则仅更新检查时间戳，不做冗余写入；
3. **快照归档**：若指纹不一致，立即将当前生效文件复制并重命名归档至 `history/{YYYYMMDD}_{old_version}_{filename}`；
4. **覆盖生效**：将最新解析的 Markdown 文件写入当前生效文件，版本号递增；
5. **审计追溯**：在 `changelog.json` 中追加差异变动细节与事件说明。
