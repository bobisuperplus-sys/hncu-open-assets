## 🏢 学院内设基层教学与行政机构

学院设有 **4个教学专业系** 与 **2个行政教辅服务机构**：

```mermaid

    A[建筑与城市规划学院] --> B[行政与教辅服务]
    A --> C[专业教学系]

    B --> B1[党政综合办公室]
    B --> B2[学生工作办公室 / 分团委]

    C --> C1[建筑学系]
    C --> C2[城乡规划系]
    C --> C3[风景园林系]
    C --> C4[城市设计系]

    D --> D1[建筑设计研究所]
    D --> D2[城乡规划设计院联合研究中心]
    D --> D3[数字化建筑与虚拟仿真实验室]
```
