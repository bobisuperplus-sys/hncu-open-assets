# 学术与备考资料库 (Academics & Examination Resources)

本目录系统归档了湖南城市学院（HNCU）各学院方向的**历年期末考试官方真题试卷**、**期末考前复习大纲**及**课程分模块专项题库**，旨在为全校师生、校友及自学者提供真实、权威、高参考价值的学科学术数字资产底座。

> [!NOTE]
> **📢 数据来源与免责声明 (Data Sources & Disclaimer)**：
> - **数据主要来源**：本目录收录的历年期末考试真题、期末考前大纲及专项复习题库，**主要来源于网络公开交流平台 [爱助攻网 (湖南城市学院版块)](https://www.aizhugong.com/forum-890-1.html)** 及在校同学的公开分享。
> - **公益定位说明**：本项目及维护团队**仅负责公益性质的数据收集、文件名规范化脱敏、多学年分层整理与长期归档**，不对试卷与题库内容享有任何原创著作权，版权均归属原出题教师、原作者或出处机构所有。
> - **非商业与合规用途**：所有资料全量免费开源共享，**仅用于在校同学课程自学、考前复习与学术交流，严禁任何第三方用于商业转售、付费下载等营利行为**。
> - **侵权与下架处理**：若原作者、学校相关教研室或出处机构认为有关资料不适宜公开或涉及权益诉求，请通过 GitHub Issue 与我们联系，我们将在收到通知并核实后第一时间进行删除或下架处理。

> [!IMPORTANT]
> **多学年版本演进设计**：
> 考虑到同一门科目的课程大纲、命题风格及题库会随学年不断迭代更新，本仓库所有学术资源均严格采用 **`学科/学年(或版本年份)/具体文件`** 的二级目录分层结构进行归类存放。便于新学年资料的持续增量纳入与追溯对比。
