# 学术与备考资料库 (Academics & Examination Resources)

本目录归档了湖南城市学院（HNCU）各专业方向的**往年期末考试真题试卷**、**期末复习大纲**及**课程考前专项题库**，旨在为全校师生及自主学习者提供真实、系统、高参考价值的学科学术资料底座。

所有资料均已完成**学年、学期、课程名称及题型结构**的标准化标注与去杂整理。

## 🤝 贡献与规范建议 (Contributing)

1. **命名规范**：
   - 试卷类：`[学年-学期]_[课程名称]_[期末/期中考试]_[A/B卷]_[专业].pdf`（如 `2024-2025-1_网络管理技术_期末考试A卷(网络工程).pdf`）
   - 复习类：`[学年-学期]_[课程名称]_[资料内容与题型].pdf`
2. **脱敏保护**：
   - 上传前请确保去除个人姓名、学号、批阅成绩或教师私密签名，保护个人与师生隐私；
   - 欢迎广大城院校友提供更多学院（土木、计科、建规、马院等）的公共课与专业课往年真题！
